# Synthetic examples

Procedural brushed-metal-like images generated by `scripts/generate_examples.py`; they are not photographs of real products.

- `normal_1.png`..`normal_3.png`: normal samples. Upload to the reference and independent calibration sets.
- `scratch_1.png`: a dark diagonal scratch; detection demo only.
- `foreign_object_1.png`: an embedded dark particle/chip; detection demo only. Anomaly images must never be used for calibration.
